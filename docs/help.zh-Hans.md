何处 Whereabouts  ·  使用指南

本指南同时适用于 Mac 和 iOS(iPhone / iPad)版。大部分功能通用,
只是操作方式不同——Mac 用鼠标右键 / 快捷键的地方,iOS 对应长按 / 滑动手势。
iOS 专属内容见「📱 iOS 版」一节;标注 (macOS) 的章节仅 Mac 版适用。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  📝  录入物品
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在顶部输入框写一句话,回车提交。

支持的句式:
  · 充电宝 在 卧室抽屉
  · 护照 → 保险箱
  · 双立人菜刀是 2024 年在山姆买的
  · 书房桌上有 AITO 专项游戏采集底座
  · 床头柜上的钥匙

自动抽取:型号、颜色、购买日期、购买渠道、容量/规格。

一次记多条:换行、分号、逗号、顿号、「然后」「以及」都能切分。
  · 钥匙在玄关,雨伞在门口
  · 3 个 Magic Keyboard 键盘在书房;2 副耳机在卧室

数量量词会原样保留(不会被自动删掉)。

多件物品共用一个位置:
  写 "iPhone、AirPods、Apple Watch 在书房抽屉" 时,
  三件物品都会挂到"书房抽屉"——不只是第一件。
  同一次输入里没有写位置的物品会自动继承最近那条明确填了位置的记录。

注意:中文解析,英文输入整句进物品名。
英文模式:如果中文拆分没有命中,解析器会自动尝试英文句式,
  支持 "X in Y" / "X at Y" / "Y has X" 等格式。

位置自动完成:
  · 输入框下方显示最近用过的位置 chip,点击追加到输入框
  · 文本里提到已存在的房间名 → 上方再出现「<房间> 内」chip 行,
    列出该房间的子位置,点击可直接使用
  · 位置匹配不区分大小写、全/半角:"hifi" 能命中 "HiFi"

位置有歧义时:
  你写的位置只有一段(比如「抽屉第一层」),库里却有好几个同名位置,
  会弹出「位置有点歧义,选一个」,列出它们的完整路径。
  挑一个已有位置,或选「新建顶层」。
  一次录入里有几件物品都有歧义时,会逐条问你,每一条都能保存;
  全部取消的话,原文留在输入框里。
  (macOS)写法相同的几件物品只问一次,选完一起放进去;
  只取消其中几条时,没保存的那几条会放回输入框并提示。

没有配置 AI 的情况下,输入框下方会出现紫色胶囊提示。
点击直接跳转到 偏好设置 → AI 完成配置。

  ✨  AI 理解
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

本地解析覆盖不到的奇怪命名、混写地点,可以让 AI 重新理解。

配置 AI(⌘, → AI tab):
  · Provider:Claude 或 火山引擎(两个可同时配置,随时切换)
  · 模型:Haiku 4.5 / Sonnet 4.6 / Sonnet 5 / Opus 4.7 / Opus 4.8(Claude)
           或填火山引擎模型名 / endpoint ID
  · API key:填入对应平台的密钥。key 保存在本机系统钥匙串(Keychain)中,
    只用于向你选择的 AI 服务商发请求,不会同步或上传,开发者也看不到
  · Endpoint:默认官方地址,可改成中转站 / 代理 URL
  · 「测试连接」按钮:1 秒内验证 key 是否有效
  · 「查看图文配置教程(网页)」链接:不熟悉 Claude / 火山引擎账号注册、
    充值、拿 key 流程的话,点开跟着教程一步步操作,教程里还有费用
    估算和报错排查。中英双语,Mac 和 iOS 都有这个入口。

触发 AI 理解的三种方式:
  1. 录入时勾「使用 AI 理解」
     每条录入先走本地解析瞬间落库,之后 AI 在后台异步跑。
     该行右侧显示 ✨ 旋转图标 + 「正在用 AI 理解…」,
     完成后变成 ✅「AI 已理解 ✓」,4 秒后自动消失。

  2. 详情页 → ✨ 用 AI 理解 按钮
     单条立即运行,不阻塞 UI。

  3. 多选 → 右键菜单 → ✨ 用 AI 理解
     批量后台处理,每条物品行内显示进度,可以继续其它操作。

AI 做了什么:
  · 语义级重新解析所有文字字段(名称、位置、型号、颜色等)
  · 把你录入时写的整段原文作为最高优先级参考——
    多条混写、含糊地点时 AI 能更准确地还原你的意思
  · 多件物品同时输入时,AI 只修改当前这件,不会影响其他条目的名称
  · 数量量词(「3 个」「2 副」等)会原样保留,不会被 AI 删掉
  · 必须从你已有的标签里挑一个挂上;都不合适才挂「其他」——
    AI 永远不会自创新标签
  · AI 的标签替换当前所有 tag(不叠加)
  · AI 返回 null 的字段保持原值,不抹掉已有数据
  · 购买日期只记到你说的精度:只说「2024 年买的」就只记年份,
    说到月就记到月,不会被补出具体的月或日

AI 位置容错:
  AI 能看到你本机所有现有位置,遇到拼写偏差时会自动复用最相近的已有位置,
  而不是建一个新的。容错范围涵盖:1-2 字符差异、同音字、繁简转换、
  大小写差异、全角/半角差异。
  例:输 "塑料袋抽屉",已有 "塑料抽屉" → AI 直接复用"塑料抽屉"。

还原 AI 修改:
  详情页历史时间线里,AI 修改 name 的那一行右侧有 ↩ 还原 按钮。
  点一下可改回 AI 修改之前的名字。
  iPhone 上,AI 刚改完名字时,列表行上还会出现「一键还原」小按钮,
  约 10 秒后消失。

AI 用量统计(偏好设置 → AI):
  顶部用量 section 分三列展示:今天 / 本周 / 本月。
  每列显示:调用次数 / input token / output token / Claude 估算 USD。
  月初自动归零;也可手动点「重置」清空。
  口径说明:token 数直接取自 API 响应的 usage 字段,
  与 Anthropic / 火山引擎账单口径一致。

火山引擎用户可在 AI tab 的火山引擎 section 里填「输入 ¥/百万 token」
和「输出 ¥/百万 token」两个可选价格字段(单价可在火山方舟控制台各 model
详情页查到)。填写后用量统计区会多一行 ¥ 估算,跟 Claude 的 $ 估算并列
显示;留空则只显示 calls / tokens。

隐私说明:
  仅在你主动点击 ✨ 时才发起请求。
  不发送照片和历史 log,只发当前物品的文字字段。
  API key 只保存在这台设备的系统钥匙串里,不会同步到 iCloud,
  也不会出现在导出的 JSON 或 iCloud 云盘备份里。

  📍  物品详情
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

点击列表中一项打开详情(右侧 inspector)。

右上角按钮:
  ✨ 用 AI 理解  · 调 AI 重新解析字段(需配置 API key)
  ✏️ 编辑        · 打开完整编辑表单

「用过这个吗?」四个选项:
  · ta 还在原位  → 确认仍在原位,写一条历史
  · 位置变了…   → 行内修改位置(带自动完成 chip 提示)
                   点击 chip 会直接替换输入框里的内容(不是追加)
  · 放回去了     → 标记已取用后放回
  · 不管了       → 暂时找不到,清空位置但保留历史

借出物品:
  详情页底部有紫色「借给…」按钮。
  点击后填写借出人姓名,确认后列表行显示紫色「借给:XX」标记,
  详情页顶部出现橙色「已借给 XX」徽章。
  归还时点徽章或右键菜单 → 标记已归还。
  借出和归还会作为时间线事件记录,显示「借出去 · 借给 XX」紫色行
  和「已归还 · ← XX」橙色行。

搜索框也能直接搜借出人姓名,筛选面板里的「借出」facet 可以一键看所有
借出去或在家的物品,详见「搜索与筛选」章节。

关联物品:
  · 该物品所在的关联组里,其余物品以蓝色超链接列出
  · 点击任意一件,inspector 立即切到对方的详情

底部时间线:位置变化 + 字段编辑历史合并显示
  · 蓝色  = 本地解析
  · 绿色  = 手工编辑
  · 紫色  = AI 修改 / 借出事件
  · 橙色  = 用户还原 / 归还事件
  · AI 修改名称的那行右侧有 ↩ 还原 按钮

底部:删除(进回收站,可还原)

  ✏️  编辑物品
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

详情 → ✏️ 编辑;或列表行右键 → 编辑详情…

四个区:
  · 基本      名称 + 备注
  · 可选信息  型号 / 版本 / 颜色 / 购买日期 / 购买渠道 /
              品牌(从名字自动推断,只读)
  · 照片      系统 Photos / Finder 文件两个来源
  · 标签      多选 + 自定义颜色名

标签行上的操作:
  · 右键(iPhone:长按或左滑)已挂上的标签 → 「从这件物品上移除」
    只是把标签从这件物品上摘下,标签本身还在
  · 要彻底删除一个标签,到 偏好设置 → 标签
    (iPhone:设置 → 通用 → 标签管理)

完成与取消:
  · 完成  保存改动
  · 取消  放弃这次的改动:名称、备注等字段、照片和标签都恢复成
          打开表单时的样子,这次新建但没用上的标签也会删掉。
          Mac 上按 Esc 效果相同
  · 关联物品的改动即时生效,点「取消」不会撤销
  · iPhone:表单里有没保存的改动时,不能下滑关闭,
    请点「取消」放弃,或点「完成」保存

关联物品:
  · 编辑页底部可添加 / 管理关联(也可从右键菜单「关联到…」操作)

  🔗  项目关联
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

把几件有关联的物品绑在一组,方便一起找到。

添加关联:
  · 列表行右键 → 「关联到…」
  · 详情页 / 编辑页底部的关联区

规则:
  · 一组最多 8 件,可以有无数个组
  · 双向 + 传递闭包:A↔B,再让 C 关联 A → A↔B↔C 同组
  · 两组合并:只要总数 ≤ 8 就能合并成一组

解除关联:
  · 详情页关联列表里每行右侧有 × 按钮,点击移除单件
  · 组里剩 1 件时自动解散(不留孤儿组)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

首次启动自动建 14 个预设:
  生活用品 · 3C 电子 · 厨具 · 小工具 · 办公用品 · 文具 ·
  化妆护肤 · 服饰鞋包 · 药品健康 · 食品干货 ·
  票据证件 · 玩具收藏 · 户外运动 · 宠物用品

自动建议标签:
  录入后物品名命中关键词字典 → 自动挂上匹配色的标签。
  底部 toast「已自动加标签:XX  [撤销]」,点撤销可移除。
  可在 偏好设置 → 通用 里整体关闭。

管理标签(偏好设置 → 标签 tab):
  每行可改色、改名、删除,右侧显示已挂在几件物品上。
  颜色:9 色调色板,直接点色点切换,选中色有描边 + 对勾。

删除标签:偏好设置 → 标签 tab,点该行右侧的垃圾桶按钮
  (iPhone:设置 → 通用 → 标签管理)。
  删标签只断挂载,不影响物品本身;开着 iCloud 同步时,
  它也会从其他设备的所有物品上消失。
  编辑表单里只能把标签从当前物品上摘下,不会删除标签本身。

同名标签:
  开着 iCloud 同步时,如果两台设备各自生成了同名标签(比如预设标签),
  会自动合并成一个,物品上的标签都保留。

三处都会显示品牌 chip:

  🔍  搜索与筛选
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

搜索框和录入框始终钉在顶部,展开筛选下拉时只压缩物品列表,顶部区域不移动。

搜索框旁边的 chevron 按钮控制筛选行的折叠与展开。
筛选下拉最高 280pt,位置很多时内部自动滚动。

搜索框模糊匹配:名字 / 位置 / 型号 / 颜色 / 渠道 / 借出人 / 标签名。

六行 facet 筛选:
  房间  · 只列根级位置(书房、客厅…)
          计数 = 该房间整棵子树下的物品数
          点击 → 显示该房间所有物品(含所有子位置)
  位置  · 只列非根级位置及没有房间的孤儿位置
          以完整路径显示(如「书房 > 收纳抽屉」)
          点击 → 显示精确在该路径上的物品
  渠道  · 京东 / 山姆 / 闲鱼 等
  年份  · 按购买年份
  品牌  · 从名字自动推断(不入库)
  借出  · 仅当至少一件物品被借出时才显示,有两个 chip:
          「借出去 N」— 显示当前所有不在家的物品
          「在家 M」  — 排掉借出去的,只看在家的物品

房间和位置可以同时选中:房间筛整棵子树,位置精确定位到某个节点。
点 chip 切换筛选,再点取消。「清除全部」一键重置。

已选中的筛选 chip 即使折叠筛选行也保留显示,
让你随时知道当前生效的过滤条件。

数据自动维护:
  每次启动时 app 会自动检查并清理两类历史遗留数据——
  ① 名称里含路径分隔符的脏位置(如早期 AI 偶尔产生的"书房 > 抽屉"整段当根)
  ② 大小写不同导致的同名房间重复(如两个"书房")
  有清理时底部会弹 toast 告知影响数量。
  清理完全自动,幂等无开销,干净数据不触发任何提示。
  开着 iCloud 同步时,这两项清理不会自动进行——合并位置可能
  误删另一台设备上还没同步过来的子位置。遇到重复的位置,到
  偏好设置 → 位置(iPhone:设置 → 通用 → 位置管理),
  用「合并到…」手动合并。

数据同步:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ☁️  iCloud 同步
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Mac 和 iPhone / iPad 登录同一个 Apple 账户,
数据就会通过你自己的 iCloud 自动互通。
不用注册,没有第三方服务器,开发者看不到你的任何内容。

会同步的内容:
  物品(含照片)、位置、标签、历史记录,
  以及借出、置顶、关联状态。

开始使用:
  1. 两台设备都在系统「设置」里登录同一个 Apple 账户
  2. 确认「iCloud 同步」开关开着(默认开启)
     Mac:偏好设置 → 通用;iPhone:设置 → iCloud 同步
  3. 在任意一台设备上记录、编辑、删除,
     另一台设备上一般几秒到一两分钟内就会出现

切回 app 时,会自动拉取另一台设备的最新改动。

开关旁边的标签显示当前状态:
  · 已开启    这次启动已接入 iCloud
  · 本机模式  这次启动没有用上 iCloud(开关关着,或这次没能启用同步),
              数据照常保存在本机;没能启用时,重新打开 app 会再试一次
改动开关后,要到下次打开 app 才生效。
关掉同步后,数据只存在这台设备上,仍可用 JSON 导出 / 导入搬运。

查看同步状态:
  Mac:偏好设置 → 通用 → iCloud 同步
  iPhone:设置 → iCloud 同步
  · iCloud 账号    已登录(能取到姓名时显示姓名)/ 未登录 iCloud /
                   受限(家长控制或设备管理)/ 暂时不可用
  · 账号识别码     苹果不允许 app 读取你的 Apple ID 邮箱,
                   所以这里显示一串识别码。
                   两台设备上的识别码相同,就是同一个 iCloud 账号。
  · 上次收到改动   最近一次从 iCloud 收到改动的时间
  · 上次上传改动   最近一次把改动送上 iCloud 的时间
  · 出错提示       同步出问题时,用一句话说明原因,
                   例如「iCloud 储存空间已满,新改动暂时无法上传」。
                   网络短暂中断这类会自动恢复的问题不会打扰你。
  · 立即同步       先保存还没保存的改动,等这一轮上传和下载跑完,
                   再告诉你结果:「已与 iCloud 同步」/
                   「未登录 iCloud,无法同步」/
                   「同步出错,稍后会自动重试」
  上次收到 / 上传、出错提示和「立即同步」只在同步生效时显示。

iPhone 上的「立即同步」:
  在物品页下拉刷新,或点右上角的 ☁️ 按钮,效果与设置里的
  「立即同步」相同。☁️ 按钮只在开着 iCloud 同步时显示。

没登录 iCloud 时:
  设置里会说明这台设备还没登录 iCloud,数据暂时只存在本机。
  到系统「设置」里登录 Apple 账户(和另一台设备同一个),
  登录后会自动开始同步。

不会同步的内容:
  · AI 的 API key 只保存在这台设备的系统钥匙串里,不会同步
  · 各项设置也是每台设备单独的,换了设备要重新配置一次 AI
  · iCloud 云盘备份文件不参与同步(见「数据导出与导入」一节)

遇到问题:
  · 设置里提示「本机数据库这次没能打开,当前是临时模式:改动不会保存」,
    或打开 app 看到「数据暂时打不开」:数据文件还在,没有丢。
    彻底退出 app 后重新打开;如果一直这样,请联系作者(见「关于」)。

  💾  数据导出与导入
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

导出:主窗口右上 ⬆ 按钮

  照片(base64)/ 位置路径 / 历史记录 / 标签 / 借出状态 / 置顶 / 关联关系。
  确认后选择保存路径,生成 JSON 文件。
  注:API key 等敏感信息不包含在导出文件里。

导入:⌘, → 数据 tab → 批量从 JSON 导入…(iPhone:设置 → 数据)
  点击后弹出确认对话框,提示导入会追加到现有数据。
  「导入时跳过重复项目」开关(默认开启):
    · 开启时:名称 + 位置完全相同的物品会被跳过,不重复导入。
    · 关闭时:所有条目强制导入,包含重复物品——
      关闭前请确认,重复物品难以批量删除。
  开着 iCloud 同步时,导入的物品也会同步到其他设备。

iCloud 云盘备份:⌘, → 数据 tab → iCloud 云盘备份(iPhone:设置 → 数据)
  点「立即备份」,把全部物品存成一个 JSON 文件,放进
  iCloud 云盘 › Whereabouts 文件夹
  (Mac 的访达、iPhone 的「文件」app 里都能看到)。
  · 每台设备写自己的文件,文件名带设备类型和一小段本机标识,
    例如 whereabouts-backup-iPhone-3F2A.json
  · 平时也会自动备份:Mac 在退出 app 时,
    iPhone 在离开 app(切到后台)时。物品没有变化就跳过;
    一件物品都没有时,不会写出空备份
  · 它是一份看得见的保险备份,不参与同步:
    不会读取、合并其他设备的文件,也不会改动你的物品
  · 要从备份恢复:用上面的「批量从 JSON 导入…」选中那个文件
  · 提示「备份失败」时,确认已登录 iCloud 并开启 iCloud 云盘
  · 旧版「手动同步」留下的重复物品不会自动删除,需要手动清理

清空所有:⌘, → 数据 tab → 清空所有数据(iPhone:设置 → 数据)
  危险,需要二次确认(建议导出后再操作)
  会清除所有物品、位置、历史记录与标签,无法撤销。
  开着 iCloud 同步时,登录同一个 Apple 账户的其他设备上的数据
  也会一起被清空。
  出错时不会删除任何东西,并显示原因。
